# 共享表单控件

`form-controls.js` 和 `form-controls.css` 为八个插件共用的维护源。修改后运行 `python workspace-tools/sync-ui-controls.py`，脚本把带标记的生成块放在每个插件 `client-bridge.js`、`style.css` 末尾。构建会检查副本，避免独立安装包的控件漂移。

下拉浮层保留真实 select 作为数据源，在控件原位置的下方展开，底部空间不足时向上展开，并随滚动、窗口大小和缩放重新定位。浮层没有遮罩、不禁用页面背景；点击外部、移焦、Tab 或 Escape 关闭。支持动态选项、单字段赋值同步、禁用选项、选项搜索、键盘、移动端及桌面嵌入边界。隐藏 select 不改变 disabled；选择时发出 input 和 change，打开及取消不修改值。组件只观察当前插件，不修改宿主样式或原生全局原型。复选框和单选框使用真实 input 的样式，已有 switch 保留原实现。

影视编辑的影片选择为独立二级弹窗。搜索和筛选只刷新候选列表，点击影片才切换编辑对象；未保存草稿沿用阻止切换规则。

本地浏览器验证位于忽略的 `workspace-tools/tests/`，不进入安装包或提交索引。
