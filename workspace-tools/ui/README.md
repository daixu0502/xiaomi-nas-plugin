# 共享表单控件

`form-controls.js` 和 `form-controls.css` 为八个插件共用的维护源。修改后运行 `python workspace-tools/sync-ui-controls.py`，脚本把带标记的生成块放在每个插件 `client-bridge.js`、`style.css` 末尾。构建会检查副本，避免独立安装包的控件漂移。

下拉浮层保留真实 select 作为数据源，在控件原位置的下方展开，底部空间不足时向上展开，并随滚动、窗口大小和缩放重新定位。浮层没有遮罩、不禁用页面背景；点击外部、移焦、Tab 或 Escape 关闭。支持动态选项、单字段赋值同步、禁用选项、键盘、移动端及桌面嵌入边界。所有下拉菜单取消内部搜索框，打开时聚焦当前选项，避免唤起手机软键盘。选择框允许收缩，长名称显示省略号、完整名称在选项列表中换行。隐藏 select 不改变 disabled；选择时发出 input 和 change，打开及取消不修改值。组件只观察当前插件，不修改宿主样式或原生全局原型。复选框和单选框使用真实 input 的样式，已有 switch 保留原实现。

影视编辑的影片选择为独立二级弹窗。搜索和筛选只刷新候选列表，点击影片才切换编辑对象；未保存草稿沿用阻止切换规则。

本地浏览器验证位于忽略的 `workspace-tools/tests/`，不进入安装包或提交索引。

## 清晰工作台

`workbench.css` 和 `workbench.js` 为八个插件共用的工作台维护源，随同步脚本写入最后加载的 CSS 与 `client-bridge.js`。统一浅色背景、蓝色主操作、紧凑列表、分区间距和弹窗；移动端保留单行菜单和深色适配。只调整现有控件的显示，不替换插件的业务表单。

桌面端在插件自己的嵌入边界内设置侧栏和内容滚动区，标题使用宿主窗口提供的插件名，页面不再增加顶栏或侧栏插件名。窄窗口自动改用顶部导航。原版本节点移入导航末尾；插件版本与公共权限组件版本分两行显示，接口更新仍写入原节点，影视编辑的权限组件版本子节点也保持原有绑定。移动端版本仍在页面底部显示，不复制版本值或写死运行版本。

多列卡片按内容区实际宽度切换为一列或两列，两列均分整行；指标、列表等完整分区跨整行，避免全宽元素配合自动列数留下空列。SSH 恢复分为状态、开机恢复、应急恢复、操作记录四页，恢复公钥管理使用独立弹窗。Docker 默认显示容器，网络与存储卷分别成页，引擎控制与系统信息在设置页。定时任务默认显示任务及指标。快传分为有效分享链接、有效上传入口、全部记录和设置；新建分享使用弹窗，文件浏览器可从其上方打开，关闭后恢复原表单和焦点。

窗口高度以实际 micro-app 容器为准，仅在其没有可用高度时回退父级。绝对定位的插件窗口不能受宿主普通文档流高度限制，否则旁边一个按钮就可能把整个内容区裁成一条。

影视编辑的影片选择栏独立于各功能面板，批量集数、文件重分配、全库修复和修改记录均可打开选择器；筛选不改变当前影片，原未保存草稿检查继续生效。编辑表单与官方参考在宽窗口中并排。Mihomo 的概览集中运行状态、策略组与代理提供者，原规则、访问范围、内核更新与 Docker 代理移入设置。下载设置分为服务与接入、下载与 BT、内核更新、种子与缓存四组，完整保留局域网接口、密钥、Openlist、两套内核更新及清理功能。NAS 概览的存储与常用服务分区在宽窗口并排。

## 统一文字样式

`typography.css` 是八个插件的文字样式维护源，参照已安装 Xiaomi 客户端设置页的 `MiSans`、14px/20px/400 正文和 12px 辅助文字。优先复用宿主已有的 MiSans，提供苹果、Windows、Android 无衬线字体回退，不复制或分发官方字体文件。

同步脚本自动识别每个插件最后加载的本地 CSS，在该文件末尾生成 `SHARED TYPOGRAPHY` 块，避免不同页面的 style/palette 加载顺序覆盖字体。统一标题、标签、按钮、页签、辅助文字、状态和代码/日志的字体、字重及行距；代码值与日志保留等宽，手机文字输入保持 16px。所有选择器限定在插件根节点内。

桌面客户端采用独立字号变量：正文、说明段落、按钮、菜单及字段值统一为 16px/24px，包含代码输入、只读值和公钥指纹；原始字段名、日期、徽标及侧栏版本为 14px/21px，日志/配置编辑器为等宽 14px/22px；标题 22px、分区标题 18px。全部字号由 `typography.css` 维护，工作台皮肤不再覆盖字号变量。通用文字容器先继承字号，清除业务样式中遗留的小字号，再按语义层级覆盖；图标字形保持独立尺寸。桌面辅助颜色加深，使用系统默认字体平滑。手机端保留原有基础字号、行距和颜色。缩放仍由宿主控制，插件没有设置整体 zoom/transform，也不修改宿主字体。

## 手机单行浮动菜单

`mobile-navigation.css` 和 `mobile-navigation.js` 为有 `.tabs` 菜单的插件提供单行吸顶导航。菜单不换行，空间不足可横向滑动；选中项变化时只滚动菜单本身，不调用会影响页面垂直位置的 `scrollIntoView`。支持方向键、Home/End 和减少动态效果设置；菜单内的触摸手势不触发内容区域的翻页手势。

同步工具向已有菜单的插件写入生成块，SSH 恢复的四页菜单同样使用此组件。桌面端使用侧栏。移动端消除插件内部会妨碍 sticky 的滚动祖先，保留宿主滚动容器；相关监听仅响应点击、尺寸和 DOM 变化，无网络轮询或周期任务。

控制中心的三项导航使用 `tabs-equal`，在手机端等分可用宽度；其他较长菜单保留按需横向滚动。快传的三项统计固定为一行三列，各列使用一致的竖向分隔线，独立于通用两列指标的手机边框规则。定时任务只保留任务、执行记录、模板，重复的设置页及其近期记录副本已移除。
