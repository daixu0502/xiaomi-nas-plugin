# 小米 NAS 控制中心

## 功能说明

- 查看 CPU、内存、温度、磁盘容量和实时网络流量。
- 查看 CPU / 内存进程排行、连接信息及健康提示详情。
- 查看硬盘 SMART 信息、健康状态及相关指标。
- 查看和重启受支持的系统服务，释放内存缓存、整理系统日志。

## 如何使用

### 安装与更新

使用完整源码或解压后的安装包，在本插件目录内执行。WSL / Linux 通过 root SSH 连接 NAS：

```bash
bash manage.sh install --ip 192.168.31.100 --users u123456789
```

在 NAS 本机以 root 运行时，省略 `--ip`：

```bash
bash manage.sh install --users u123456789
```

将示例 IP 和用户 ID 换成自己的值。直接运行 `bash manage.sh` 可进入交互菜单；安装和更新使用同一入口。安装后在小米客户端应用列表中打开本插件，必要时完全退出客户端再重进。

### 查看状态与维护

1. 打开“控制中心”，查看设备状态和健康提示。
2. 点击 CPU、内存、网络或健康提示，查看相应进程及详细信息；按需搜索或刷新。
3. 在硬盘信息中查看 SMART 结果，结合设备提示判断是否需要进一步检查。
4. 需要维护时，选择受支持的服务重启、内存缓存释放或日志整理操作，核对提示后确认。

### 卸载

```bash
bash manage.sh uninstall --ip 192.168.31.100 --users u123456789
```

NAS 本机省略 `--ip`，按提示确认。其他参数可用 `bash manage.sh install --help` 查看。

## 注意事项

- NAS 存储池需已挂载，目标用户需在小米客户端完成初始化；远程安装需能使用 root SSH 登录。
- 服务重启和系统维护影响整台 NAS，操作前确认其他用户及容器没有重要任务。
- SMART 信息取决于硬盘及系统工具支持；健康提示用于排查问题，不能替代数据备份或硬盘检测。
- 进程网络速度根据连接计数采样，短连接可能遗漏；UDP / QUIC 不提供同等测速，代理流量可能归属代理进程。
- 同一文件系统上的目录共享容量，不能将目录容量相加视为总存储；共享内存也可能在多个进程中重复计入。
- 卸载仅移除插件及对应权限，保留系统服务和用户文件。
- 使用安装脚本卸载会取消本插件的自动恢复登记；仅在应用市场删除时，恢复服务可能将插件补回。
