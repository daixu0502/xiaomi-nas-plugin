# 小米 NAS 文件快传

## 功能说明

- 为 NAS 中的文件、文件夹生成带密码、有效期和次数限制的下载链接。
- 创建指向指定文件夹的上传入口，接收他人上传的文件。
- 查看分享记录，复制链接、延期、立即失效或删除记录。
- 设置外部访问地址，启动、停止和重启分享服务。

## 如何使用

### 安装和更新

1. 在电脑的 **Ubuntu（WSL）终端**中，进入有 `manage.sh` 的插件文件夹，运行：

```bash
bash manage.sh
```

2. 输入 `1`，选择“安装 / 更新”，按提示输入 NAS 的 IP，再选择自己的账号。只有一个账号时会自动选择。
3. 等待提示安装成功，再到小米客户端的应用列表打开本插件。看不到时，退出客户端后重新打开。

更新也是这三步，已有配置会保留。需要先让电脑能用 root SSH 登录 NAS；还没开启时，见[SSH 开启步骤](../nas-root/README.md#开启-ssh)。

### 创建与管理分享

1. 打开“文件快传”，在“设置”页确认分享服务已启动。
2. 在“创建”页选择文件分享、文件夹分享或上传入口，并选择对应文件或目录。
3. 设置密码、有效期和次数限制，创建后复制链接发送给接收者。复制受客户端限制时，按提示手动复制。
4. 在“分享记录”中查看链接、延期或立即失效；不再需要时删除记录。
5. 需要公网访问时，配置路由转发或 HTTPS 反向代理，并在“设置”页填写实际外部基础地址。

### 卸载

再次运行 `bash manage.sh`，输入 `2` 选择“卸载”，按提示选择账号并确认。

请用这个菜单卸载；只在小米客户端里删除，插件可能会自动恢复。手动指定账号等用法见[进阶说明](../docs/plugin-installation.md)。

## 注意事项

- NAS 存储池需已挂载，目标用户需在小米客户端完成初始化；远程安装需能使用 root SSH 登录。
- 局域网端口以设置页显示为准。仅填写外部地址不会自动配置路由器或反向代理。
- 链接、密码和上传入口应只发给预期接收者；上传入口会向选定目录写入文件，注意剩余空间。
- 文件夹下载会流式生成 ZIP，读取下载时的实时内容；不支持断点续传，传输开始后即计次，中断重试会再次计次。
- 文件夹分享不包含隐藏文件、符号链接和特殊文件；最多 10000 个文件及子目录、64 层，同时最多两个文件夹下载。
- 延期不能重新开放已手动失效或次数用完的分享。删除记录不会删除源文件或已上传文件。
- 停止服务或卸载插件后，分享链接暂不可用；原文件和已上传文件保留。
- 使用安装脚本卸载会取消本插件的自动恢复登记；仅在应用市场删除时，恢复服务可能将插件补回。

- 关闭插件页面不会停止后台服务；通过页面主动停止后，恢复检查不会擅自重新启动。
