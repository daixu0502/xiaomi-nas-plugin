# 小米 NAS 文件快传

## 功能说明

- 为 NAS 中的文件、文件夹生成带密码、有效期和次数限制的下载链接。
- 创建指向指定文件夹的上传入口，接收他人上传的文件。
- 查看分享记录，复制链接、延期、立即失效或删除记录。
- 设置外部访问地址，启动、停止和重启分享服务。

## 如何使用

### 安装和更新

1. 在电脑的 **Ubuntu（WSL）终端**中，进入有 `manage.sh` 的插件文件夹，运行：

```bash
bash manage.sh
```

2. 输入 `1`，选择“安装 / 更新”，按提示输入 NAS 的 IP，再选择自己的账号。只有一个账号时会自动选择。
3. 等待提示安装成功，再到小米客户端的应用列表打开本插件。看不到时，退出客户端后重新打开。

更新也是这三步，已有配置会保留。需要先让电脑能用 root SSH 登录 NAS；还没开启时，见[SSH 开启步骤](../nas-root/README.md#开启-ssh)。

### 创建与管理分享

1. 打开“文件快传”，在“设置”页确认分享服务已启动。
2. 在“分享链接”页点击“新建分享”，在弹窗中选择文件或文件夹；接收文件时，在“接收上传”页点击“创建上传入口”。
3. 设置密码、有效期和次数限制，创建后复制链接发送给接收者。复制受客户端限制时，按提示手动复制。
4. 在“分享链接”和“接收上传”中按类型管理链接，包含过期等历史记录；可复制、延期、立即失效或删除记录。
5. 需要公网访问时，配置路由转发或 HTTPS 反向代理，并在“设置”页填写实际外部基础地址。

### 卸载

再次运行 `bash manage.sh`，输入 `2` 选择“卸载”，按提示选择账号并确认。

请用这个菜单卸载；只在小米客户端里删除，插件可能会自动恢复。手动指定账号等用法见[进阶说明](../docs/plugin-installation.md)。


### 传输记录与流量

“传输记录”显示最近 500 次文件上传、下载和文件夹 ZIP 传输，支持按方向筛选，并显示今日及累计字节数。记录从升级后的新传输开始，不能从旧分享使用次数推算过去流量。页面打开时每 5 秒刷新，关闭页面后服务继续处理传输。

记录保存在本用户 `var/transfers.json`，使用独立文件锁和同目录原子替换，不改旧分享记录；日汇总保留最近 30 天，累计数持续保留。仅记录文件名、方向、时间、字节数和服务器完成/中断状态，不记录访问口令、令牌或链接。下载流量统计服务器确认写出的块；上传统计收到的数据。完成表示服务器已完成读写，不能证明接收方已保存副本。中断上传继续回滚使用次数并删除临时文件；文件夹下载沿用开始计次规则。

## 注意事项

- NAS 存储池需已挂载，目标用户需在小米客户端完成初始化；远程安装需能使用 root SSH 登录。
- 局域网端口以设置页显示为准。仅填写外部地址不会自动配置路由器或反向代理。
- 链接、密码和上传入口应只发给预期接收者；上传入口会向选定目录写入文件，注意剩余空间。
- 文件夹下载会流式生成 ZIP，读取下载时的实时内容；不支持断点续传，传输开始后即计次，中断重试会再次计次。
- 文件夹分享不包含隐藏文件、符号链接和特殊文件；最多 10000 个文件及子目录、64 层，同时最多两个文件夹下载。
- 延期不能重新开放已手动失效或次数用完的分享。删除记录不会删除源文件或已上传文件。
- 停止服务或卸载插件后，分享链接暂不可用；原文件和已上传文件保留。
- 使用安装脚本卸载会取消本插件的自动恢复登记；仅在应用市场删除时，恢复服务可能将插件补回。

- 关闭插件页面不会停止后台服务；通过页面主动停止后，恢复检查不会擅自重新启动。

页面右上角“外观主题”可选择跟随系统、浅色或深色，本地记忆选择；跟随系统时自动响应系统外观变化。

## 在线更新

电脑端点击左下角版本号，手机端点击底部版本号打开更新弹窗；发现新版本显示 `NEW`。打开插件时按缓存策略自动检查，也可手动点击“检查更新”。点击“立即更新”并确认后，后台自动下载、校验和安装，关闭页面仍会继续。完成后关闭插件窗口再打开。

“更新代理”支持 HTTP/HTTPS，例如 `http://127.0.0.1:7890`；按 NAS 账号在八个插件间共用，仅用于检查和下载安装包，不改变其他服务代理。认证用户名、密码分别填写，密码不会回传页面。修改后保存，启用代理时失败不会自动直连。

更新保留配置、任务、启用状态、已更新内核和 SSH 材料，验证失败自动回退。有下载、传输或关键任务时请稍后更新。首次使用需通过原安装器安装一次含在线更新组件的版本。签名发布与恢复细节见 [在线更新组件说明](installer/updater/README.md)。
## 稳定性与关闭页面后的行为

同名上传完成后使用原子不覆盖提交，发生冲突自动添加后缀并返回实际名称。最多 32 个连接、8 个活动传输和 2 个文件夹压缩，读取空闲超过 60 秒会释放连接并清理本次临时文件。关闭插件页面不会停止已经开始的传输。运行日志位于官方 tmp/runtime 的真实内存挂载中，分享令牌不进入普通请求日志。
