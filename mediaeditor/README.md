# 影视编辑

独立编辑小米官方影视媒体库。保留原厂影视插件和播放器，不改写官方插件源码。

- 按自有媒体库浏览已识别影片，查看本地记录编号、影片代码、系列与文件信息。
- 使用 NAS 上的官方迅雷刮削库搜索片名，显示完整影片代码、系列源代码、系列源标识与本地系列编号。可分别带入代码、片名、系列和季信息。
- 更正影片代码、片名、系列归属、季号/名称。直接改代码只改字段，不会自动重新刮削海报、演员和简介。
- 批量修改文件季号/集号，按文件名提取或连续编号，支持多版本片源明确允许重复集号。
- 影片代码重复时列出占用代码的影片名称和本地编号，可放弃草稿后前往修改冲突影片；保留官方唯一约束，不提供强制覆盖或重复代码写入。
- 文件关联重分配支持选择当前影片文件，或检索文件库中的任意可编辑文件（包括尚无影片关联的文件）。沿用官方添加/删除关联及触发器，预览会明确显示观看/收藏记录和原影片记录的删除影响。
- NAS 管理员可开启全库模式，编辑跨账号、共享及无关联影片；全库检查可修复引用计数、失效系列、无效季集号、失效外键关联、上次观看文件指向和官方搜索索引。
- 保存前预览差异，建立 WAL 一致性备份，在事务中检查旧值与关联范围，保留原有 FTS 分词扩展及触发器。修改后可预览精确回退；后续被其他操作修改过的记录拒绝覆盖回退。

各功能页上方均保留“当前编辑影片”和“选择影片”。在批量集数、文件重分配、修改记录或全库修复页也可直接选择影片，选定后保留当前页面。筛选和搜索候选列表不会改变当前影片；存在未保存草稿时，先保存或重置草稿，再切换影片。

## 安装与卸载

在 WSL/Linux 解压安装包，进入 `mediaeditor` 目录：

```sh
bash manage.sh install --ip 你的NAS地址 --users 你的NAS账号
bash manage.sh uninstall --ip 你的NAS地址 --users 你的NAS账号
```

使用现有公共权限组件，新增独立 `mediaeditor` 授权，不提供任意 SQL、任意文件操作或任意 root 命令。权限组件升级兼容原有模块，不修改其他插件的私有实现与任务配置。

## 权限与保存位置

默认只编辑当前账号拥有、且未被其他账号/共享库引用的条目；NAS 管理员可明确开启全库模式。管理员资格在服务器从 NAS 账号配置核验，执行、回退时重新检查，不能通过请求参数伪造。全库模式包含其他账号和共享记录。本地记录主键仍只读，影片代码重复时拒绝覆盖。

- 源码：标准插件 `src/files`、`src/ui` 与 `scripts/control`，受原厂摘要校验。
- 公共权限模块：`/data/minas/privileged/modules/mediaeditor/`，仅安装自身四个 Python 模块。
- 用户配置/普通持久状态：插件 `etc/var`，由现有恢复组件归入 `/data/minas/plugins/data/<用户>/mediaeditor/`。
- 受保护的修改计划、搜索参考、全库一致性备份和修改记录：`/data/minas/plugins/data/<用户>/mediaeditor/protected/`。目录 root:root 0700、文件 0600，与用户所属的 etc/var 平级，卸载后保留。
- 所有账号共用的编辑锁：`/data/minas/privileged/modules/mediaeditor/var/write.lock`，root 私有。安装器在公共权限组件独占锁内迁移旧记录，保留写锁 inode；有冲突时拒绝覆盖，失败回退，断电后可按记录继续迁移。
- 普通可重建缓存、日志和运行暂存：官方 `tmp` → `plugintmp/mediaeditor/`。本插件没有常驻端口、PID 或后台轮询，也不把 root 授权状态放入该缓存。

备份在每次实际修改前创建，历史保留最近 100 条供查看；备份不自动删除。空间不足时拒绝继续编辑。结构操作先在受保护的数据库副本中运行真实官方触发器，生成记录变化预览；执行时持有写事务，数据库自预览后发生变化则要求重新预览。确认前可能发生的观看/收藏记录删除会明确显示；移走最后一个关联时，官方触发器也可能删除原影片记录。

回退恢复本次实际改变的记录，包含删除的影片、关联和观看/收藏记录，保留未涉及的后续数据；相关记录已再次变化时拒绝覆盖。回退结构记录时仅在当前 SQLite 连接中临时抑制触发器，避免恢复过程再次删除观看数据，不改官方触发器定义或表结构。修复操作的回退若会恢复原先已有的外键错误，会在预览中明示。

全库扫描不写入业务数据；每次展示最多 500 项问题，可选最多 200 项预览修复，完成后可再次扫描。不会猜测影片代码或自动删除无关联影片。文件库查询每页最多 100 条，支持按文件名、路径或编号检索；影片选择每页 500 条，可翻页和按本地编号查询。结构操作按已检查的官方表/触发器结构指纹适配，未知结构拒绝执行。只提供界面内的结构化修复，不提供任意 SQL 或系统命令入口。

## 代码的对应关系

官方搜索 `id` 对应本地 `media.midb_id`。电影系列源编号经 `tmdb_movie_<编号>` 映射为本地 `collection.id`，电视剧使用官方剧目映射；二者都不能把上游系列编号直接填进 `media.collection_id`。界面通过搜索参考自动完成转换。

`file.session` 是原厂数据库的文件季号字段，`file.episode` 是单文件集号；它们与季元数据中的“总集数”不同。本插件不把文件数量当作总集数改写。

底层官方搜索属于内部接口，按已验证库指纹适配。固件更新导致库变化时禁用搜索，保留本地浏览与编辑；完成新版本适配后再启用。设备认证始终由 NAS 上的官方库处理，不向浏览器或安装包导出令牌，不分发官方库。

系统卸载后实际重建插件时，原厂登记统一设为 enable=true；仅例行检查不会覆盖现存的手动停用。后台服务和调度器仍按各自保存的运行意图处理，不因登记启用而启动原先停止的服务。
