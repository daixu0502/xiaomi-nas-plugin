# 影视编辑

独立编辑小米官方影视媒体库。保留原厂影视插件和播放器，不改写官方插件源码。

- 按自有媒体库浏览已识别影片，查看本地记录编号、影片代码、系列与文件信息。
- 使用 NAS 上的官方迅雷刮削库搜索片名，显示完整影片代码、系列源代码、系列源标识与本地系列编号。可分别带入代码、片名、系列和季信息。
- 更正影片代码、片名、系列归属、季号/名称。直接改代码只改字段，不会自动重新刮削海报、演员和简介。
- 批量修改文件季号/集号，按文件名提取或连续编号，支持多版本片源明确允许重复集号。
- 保存前预览差异，建立 WAL 一致性备份，在事务中检查旧值与关联范围，保留原有 FTS 分词扩展及触发器。修改后可预览精确回退；后续被其他操作修改过的记录拒绝覆盖回退。

## 安装与卸载

在 WSL/Linux 解压安装包，进入 `mediaeditor` 目录：

```sh
bash manage.sh install --ip 你的NAS地址 --users 你的NAS账号
bash manage.sh uninstall --ip 你的NAS地址 --users 你的NAS账号
```

使用现有公共权限组件，新增独立 `mediaeditor` 授权，不提供任意 SQL、任意文件操作或任意 root 命令。权限组件升级兼容原有模块，不修改其他插件的私有实现与任务配置。

## 权限与保存位置

首版只编辑当前账号拥有、且未被其他账号/共享库引用的条目；本地记录主键只读。影片代码重复时拒绝覆盖，文件关联重分配和任意全库修复不属于首版功能。

- 源码：标准插件 `src/files`、`src/ui` 与 `scripts/control`，受原厂摘要校验。
- 公共权限模块：`/data/minas/privileged/modules/mediaeditor/`，仅安装自身四个 Python 模块。
- 用户配置/普通持久状态：插件 `etc/var`，由现有恢复组件归入 `/data/minas/plugins/data/<用户>/mediaeditor/`。
- 编辑锁、受保护的修改计划、搜索参考、全库一致性备份和修改记录：`/data/minas/plugins/mediaeditor/<用户>/`；跨用户编辑锁位于该父目录。全部 root 私有，不放用户缓存，卸载后保留。
- 普通可重建缓存、日志和运行暂存：官方 `tmp` → `plugintmp/mediaeditor/`。本插件没有常驻端口、PID 或后台轮询，也不把 root 授权状态放入该缓存。

备份在每次实际修改前创建，历史保留最近 100 条供查看；备份不自动删除。空间不足时拒绝继续编辑。回退仅恢复本次修改字段，不会用旧全库备份覆盖后来发生的官方扫描或观看记录。

## 代码的对应关系

官方搜索 `id` 对应本地 `media.midb_id`。电影系列源编号经 `tmdb_movie_<编号>` 映射为本地 `collection.id`，电视剧使用官方剧目映射；二者都不能把上游系列编号直接填进 `media.collection_id`。界面通过搜索参考自动完成转换。

`file.session` 是原厂数据库的文件季号字段，`file.episode` 是单文件集号；它们与季元数据中的“总集数”不同。本插件不把文件数量当作总集数改写。

底层官方搜索属于内部接口，按已验证库指纹适配。固件更新导致库变化时禁用搜索，保留本地浏览与编辑；完成新版本适配后再启用。设备认证始终由 NAS 上的官方库处理，不向浏览器或安装包导出令牌，不分发官方库。
