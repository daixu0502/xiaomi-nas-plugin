# 小米 NAS Mihomo

## 功能说明

- 启动、停止和重启 Mihomo，切换运行模式及策略组节点。
- 导入和更新订阅、单条节点、代理提供者及规则提供者。
- 编辑并校验配置，查看运行日志，更新内核及 GeoIP / GeoSite 数据。
- 设置代理的本机或局域网访问范围，为 Docker 守护进程配置代理并检查生效情况。

## 如何使用

### 安装与更新

使用完整源码或解压后的安装包，在本插件目录内执行。WSL / Linux 通过 root SSH 连接 NAS：

```bash
bash manage.sh install --ip 192.168.31.100 --users u123456789
```

在 NAS 本机以 root 运行时，省略 `--ip`：

```bash
bash manage.sh install --users u123456789
```

将示例 IP 和用户 ID 换成自己的值。直接运行 `bash manage.sh` 可进入交互菜单；安装和更新使用同一入口。安装后在小米客户端应用列表中打开本插件，必要时完全退出客户端再重进。

### 配置代理

1. 打开“Mihomo”，在“订阅”页导入自己的订阅地址，或添加单条节点。
2. 在“概览”页启动核心并选择运行模式，在“策略”页选择节点。
3. 需要让局域网设备使用时，在“概览”页调整访问范围，并按页面显示的 NAS 地址及代理端口配置客户端。
4. 在“配置”页修改并校验配置，在“日志”页排查连接问题。
5. 需要让 Docker 拉取镜像使用代理时，在“Docker 守护进程代理”中应用设置，并检查进程加载状态和连通性。

内核、Geo 数据及订阅更新均在界面中操作；后台任务提交后可查看进度，重新打开页面可继续查看结果。

### 卸载

```bash
bash manage.sh uninstall --ip 192.168.31.100 --users u123456789
```

NAS 本机省略 `--ip`，按提示确认。其他参数可用 `bash manage.sh install --help` 查看。

## 注意事项

默认内核为 Mihomo v1.19.33（官方 ARM64 构建，Go 1.26.10）。安装和界面更新都会检查 Go 编译版本，拒绝早于 Go 1.26.10 / 1.27.3 的构建，防止重新引入 [CVE-2026-111943](https://pkg.go.dev/vuln/GO-2026-6809)。内核版本及固定摘要维护在 `src/files/core-release.sh`，插件版本仍只维护根目录 `INFO`。

受管配置仅引用非空节点提供者；首次添加或删除最后一个手动节点时会更新引用。运行日志按大小轮转，后台核心仍以自身 PID 交给系统服务管理。

- NAS 存储池需已挂载，目标用户需在小米客户端完成初始化；远程安装需能使用 root SSH 登录。
- 安装时需要联网获取并校验 ARM64 内核；安装包不是完整离线包。第三方许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
- 订阅地址和 API 密钥属于私密信息，请勿公开。代理端口以界面显示为准，多用户端口可能不同。
- 首次导入订阅会生成受管配置并备份原配置；修改已有复杂配置前建议自行备份。
- 应用或撤销 Docker 守护进程代理可能重启 Docker，影响整台 NAS 的容器；只查询状态不会重启。
- 内核更新和 Geo 数据变更可能短暂中断代理。若 Docker 正使用本插件的代理，卸载时会撤销该代理并重启 Docker。
- 使用安装脚本卸载会取消本插件的自动恢复登记；仅在应用市场删除时，恢复服务可能将插件补回。

- 关闭插件页面不会停止后台服务；通过页面主动停止后，恢复检查不会擅自重新启动。
