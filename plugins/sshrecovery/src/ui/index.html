离线应急使用步骤

  1. NAS 正常时：导入自己的恢复公钥，下载应急包，单独保存对应私钥。

  2. 准备 Portainer 管理入口，提前拉取 ARM64 BusyBox 镜像。救援容器以 root 运行，把 NAS 的 / 绑定到容器 /nas（可写），添加 SYS_CHROOT，网络设为 none，不设置自动重启。

  3. 先测试能打开 Portainer 和救援容器控制台；容器可以保持停止，故障时再手动启动。不要删除已准备的镜像和容器。

  4. SSH 无法进入时：把电脑上的应急包解压到 NAS 自己账号的 data/ssh-emergency 文件夹。

  6. 查看应急包 README 和恢复结果，再用自己的私钥从电脑实际登录 SSH。若 NAS 已无法使用 Python、Cron、Docker 和所有管理入口，需要通过其他维修途径恢复。
