# 规范与恢复服务

安装引擎维护 INFO、原厂注册、图标和规范链接，执行原厂校验后保存当前快照。
恢复组件只观察事件、选择对象并调用同一事务引擎；保存快照不安装组件或启动服务。
细节见 [恢复服务](../../common/recovery/README.md)。

原厂入口 enable、后台运行意图和实际状态分别管理。原厂清理后自动补回已托管
插件，保留原先禁用和停止意图；调度开关以权限组件中的持久状态为准，不补跑任务。
普通卸载删除数据和恢复快照并取消恢复；切换重装保留数据与原有启停状态。

监听使用 inotify 和挂载通知，空闲时不轮询源码。源码冲突、持久状态缺失或存储池
尚未挂载时停止对应修复。未完成事务先回退或完成提交后清理，再允许自动恢复。
固件清除启动入口后可由 root 执行 recovery.py bootstrap 重建监听。
