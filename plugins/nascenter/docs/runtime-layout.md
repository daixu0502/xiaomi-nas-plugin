# 插件目录与安装入口

统一入口为仓库或离线套件根 manage.sh，安装方式见 [统一安装器](../../common/manager/README.md)。
源码、持久数据、缓存、权限与恢复组件的边界见 [持久目录约定](../../../docs/scripts/data-layout.md)。

入口位于 /home/<用户>/plugin/<插件>/；校验源码位于实际已挂载存储池的
/nas/<存储池>/<用户>/plugin/pluginsrc/<插件>/，不强制 pool0。
etc/var 链接指向 /data/minas/plugins/data/<用户>/<插件>/，由用户拥有、0700。
官方 tmp 链接指向 plugintmp/<插件>/，仅放可重建缓存、普通日志和 PID。
root 访问用户缓存前必须降权。配置、断点、任务、密钥和已更新内核保持持久保存。

安装与恢复只处理当前布局；发现错误路径、链接、权限或未挂载存储池时停止，
不搬移旧布局、不创建空状态替代已丢失数据。注册信息只合并目标插件条目。

更新与切换重装保留配置及启停状态；普通卸载删除插件自有数据和快照。
用户下载、媒体文件、Docker 数据和独立 SSH 工具保持原归属。
