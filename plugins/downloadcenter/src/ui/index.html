缓存清理

需保持服务运行，仅清理未被任务使用的缓存，保留下载文件、手动种子和续传数据。

支持的下载格式

支持 HTTP、HTTPS、FTP、SFTP 直链及 BT v1 种子与磁链；不支持纯 BT v2、ed2k、迅雷和网盘解析。

下载后的 .torrent 需手动导入。暂不支持 Cookie 下载和自动解压。
