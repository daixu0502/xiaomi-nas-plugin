# 控制中心、下载中心与更新清单复用（2026-11-10）

## 版本范围

- 下载中心：1.1.63 → **1.1.64**。
- 控制中心：1.1.80 → **1.1.81**。
- 公共更新组件：2.0.1 → **2.0.2**。
- 其余六插件的源码、INFO 与版本不变，不因统一套件重新发布而递增插件版本。

## 修复与行为

### 下载中心

服务与接入改为按阅读顺序排列：紧凑的服务控制、完整宽度的接口说明、密钥、Openlist。取消无关卡片被拉成等高造成的留白。接口与密钥内部按可用宽度自动切换双栏/单栏；其他设置页卡片顶部对齐，保留所有原有操作和密钥隐藏规则。

### 控制中心

- 手动刷新会取消旧的实时请求，并立即发起新请求；旧结果不得覆盖新结果。
- 实时状态对整个请求链路设定 10 秒期限，涵盖宿主桥接、认证和响应体读取；即使宿主未及时响应取消，界面也能释放请求状态并重试。
- 原 scoped document 将事件监听绑定在插件根节点；改为监听原生 document 的 visibilitychange，并在焦点/前台恢复时恢复轮询。隐藏或卸载时取消本页读请求，卸载后不再发起轮询。
- 存储、服务、日志通过同一兼容 API 的不同 part 独立加载；实时刷新不等待慢服务探测或日志统计。局部失败保留上次结果并标明失败类别。
- Docker 后台脚本补齐公共缓存模块的安装路径。此前它独立启动时无法导入 user_state_io，可能在扫描前就退出。
- Docker 目录采用单实例、低 CPU/I/O 优先级后台扫描；不跨文件系统，不进入 overlay/overlay2 的 merged 视图。取消反复 20 秒中断重试，单次上限为 5 分钟，成功结果约每 5 分钟更新。失败退避 60、120、240、480 秒（上限 600 秒）。
- 显示扫描中、失败、上次成功采样和下次重试时间。失败或部分结果不得当作 0，不覆盖旧的成功大小。容量和剩余空间仍独立返回。

### 共用更新结果

仅修改独立公共后台，不修改其余六插件的页面副本。

同 NAS 账号任一插件成功检查后，其他插件在打开/重新进入、读取状态时直接复用完整的签名发布清单，按各自已安装版本判断是否更新；六小时内无需分别联网检查。并发后台检查在账号锁内复用，手动检查继续绕过缓存重新查询。已有窗口在未读取状态前不立即变化。检查详情显示共用清单的时间，不做常驻后台网络轮询或自动安装。

账号之间不共享候选结果；旧值不会覆盖较新的结果。安装仍重新验证签名、包大小、SHA-256、账号、内核保留策略和禁止降级规则。
