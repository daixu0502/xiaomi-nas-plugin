# 影视编辑 1.0.5：开发与部署验收

2026-10-25 新增独立 `mediaeditor` 插件。展示名称由“影视库编辑”缩短为“影视编辑”；1.0.3 按用户要求将场记板与调整滑杆图标改为蓝白扁平风格，使用 300×300 RGBA PNG。内部插件 ID 和数据位置保持不变。

## 界面更新

1.0.4 将选择影片移至二级页面，保留媒体库筛选和本地片名搜索；筛选仅刷新候选列表，点击影片才切换编辑对象。长片名按内容保持高度，修复大量条目挤压重叠，统一字体、字号、行距、复选框和单选框。

1.0.5 将八个插件的下拉菜单统一为紧贴原控件展开的圆角浮层，取消下拉菜单的居中弹窗与背景遮罩。选项较多时支持搜索，底部空间不足时向上展开；菜单随窗口缩放、尺寸变化和内部滚动定位，点击外部、移焦、Tab 或 Escape 关闭。Mihomo Geo 策略和动态代理节点也使用该控件。影视编辑顶部英文统一为 `XIAOMI SMART STORAGE`。

共享控件维护源位于 `plugins/common/ui/form-controls.js` 和 `form-controls.css`，运行 `workspace-tools/sync/sync-ui-controls.py` 同步至八个独立插件；构建会检查副本是否一致。

浏览器验证覆盖八个插件的桌面 80% 缩放、手机深色、边缘向上展开、外部点击、禁用状态、动态选项、键盘和滚动定位；Mihomo 实际界面的 Geo 与代理节点回调、影片选择内的嵌套下拉也通过检查。NAS 部署同步了版本、INFO 摘要、注册信息和恢复快照，八个插件再次通过原厂校验；现有服务进程、启用状态、配置、任务、SSH 材料和已更新内核保持一致。

## 功能

- 浏览当前账号的已识别影片，显示影片代码、系列和文件季/集号。
- 在 NAS 本机调用已验证的官方迅雷刮削库，搜索片名并显示完整影片代码、系列源代码、系列源标识和本地系列编号，可选择性带入。
- 编辑影片代码、片名、系列归属、季号和季名称。原厂主键只读，直接改代码不等同于重新刮削全部元数据。
- 批量修改文件季号/集号，按文件名提取或连续编号，预览具体变化后再确认。
- 修改前生成一致性备份；事务、旧值校验与官方 FTS 分词器共同保护原有数据。记录支持精确字段回退，遇到后来发生的变化拒绝覆盖。

当前只编辑当前账号拥有且没有其他账号/共享库引用的目标。不提供任意 SQL、跨用户全库编辑或直接覆盖重复影片代码；季“总集数”不是单文件集号，本版不修改该元数据。

## 公共组件与目录

公共权限组件升级至 **1.2.4**（API v1、布局 v3），增加独立 `mediaeditor` 模块和 sudo 授权，原有私有模块与授权保持兼容。恢复组件 **1.6.3** 增加新插件白名单。

源码唯一维护在 `mediaeditor/`。权限实现仅维护在 `plugins/mediaeditor/installer/common/modules/mediaeditor/` 四个 Python 文件中，构建包不带官方 `.so`、设备令牌、测试或运行数据。

安装后遵守标准 `src/files`、`src/ui`、`scripts/control` 层级；插件 `etc/var` 由恢复组件归入 `/data/minas/plugins/data/<用户>/mediaeditor/`。官方 `tmp` 指向对应 `plugintmp/mediaeditor/`。

受保护的编辑锁、计划、搜索参考、备份与历史保存在 `/data/minas/plugins/mediaeditor/`，由 root 私有管理，卸载后保留。此处包含影响写入的可信状态，不属于可清空用户缓存，也不混入参与原厂摘要校验的源码或公共组件代码副本。

- 八个自研插件以及官方影视均通过真机原厂完整性校验；原有权限模块版本、授权和私有代码一致，官方影视服务仍正常运行。
- 1.0.1 短名称更新、1.0.2 新图标与 1.0.3 扁平图标更新，均再次核对 INFO、前端配置、注册列表、实际图标字节、启用状态和原厂校验。

## 使用入口

在小米客户端重新打开插件列表，进入“影视编辑”。先选本地影片；搜索官方资料后按需要带入代码或系列；修改后点击预览，核对差异再保存。批量集数页同样先填写草稿，再预览保存。

部署只安装到当前使用账号，未向其他 NAS 账号自动授权。未替用户修改真实片目，修改记录初始为空。源码统一在本仓库维护；本地测试、安装包与设备专属验收资料保持本地保存。
