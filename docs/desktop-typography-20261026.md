# 电脑客户端文字可读性调整

八插件共享文字样式按 `.desktop-client` 启用桌面字号。正文、菜单、按钮及输入框由 14px 增至 16px，行高由 20px 增至 24px；辅助文字由 12px 增至 14px，行高 21px；代码及日志为 14px/22px。主标题 22px、分区标题 18px，辅助文字颜色加深，保留正文 400、按钮/选中项 500 的字重层级。

手机端保留既有字体指标及颜色。没有给整个插件设置 zoom/transform，没有引入字体文件、系统字体安装或网络字体请求；宿主提供 MiSans 时优先使用，否则由已有中文无衬线字体回退。桌面采用系统默认字体平滑，实际渲染仍受宿主缩放、操作系统和字体可用性影响。

维护源为 `plugins/common/ui/typography.css`。字号和行高使用根节点内的共享变量，生成顺序仍位于各插件最后加载的本地样式中；不调整宿主页面或其他插件的全局样式。代码及日志保留等宽字体。

本地验证覆盖八插件桌面 100% 和 80% 嵌入显示、手机模式，核对字号、行距、字体回退、宿主隔离和溢出；另回归实际 Mihomo 策略和任务编辑页、影视编辑操作与共享下拉菜单。测试代码、截图和验收记录保持本地，不进入 GitHub 或安装包。
