# 插件安装、更新和卸载

使用[统一安装器](../plugins/common/manager/README.md)。八插件只保留仓库／套件根目录 manage.sh。

- 完整 ARM64 离线套件包含默认内核；安装及默认首次启动不访问外网。
- 首次从旧版切换使用 reinstall，一次处理全部账号已有插件，保留数据和启停状态。
- 普通 uninstall 彻底删除选定账号插件数据；下载文件、媒体、容器和独立 SSH 工具不属于插件数据。
- 在线更新保留，安装与回退由同一公共引擎完成；旧更新器必须先通过统一套件切换。
- INFO 仍是各插件版本唯一维护源。根 dist 保存套件、更新包、组件包及签名清单。
- 安装直接使用当前 /data/minas 布局，不探测或搬迁旧目录。
- 原厂校验固定子进程 LC_ALL=C、LC_COLLATE=C、LANG=C；不能跳过校验或改变系统语言。
- 真机验收必须检查八插件的原厂校验、实际服务、原配置及特殊受保护材料，隔离测试不能替代。
