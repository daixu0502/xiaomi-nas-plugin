# 下拉选择框与任务时间字段修复

Mihomo 策略组使用长节点名称时，移动端单列网格的自动最小宽度会把选择框撑出卡片。统一下拉按钮采用 `min-width:0`、边框盒及最大宽度约束，移动端策略网格使用 `minmax(0,1fr)`。收起时名称省略，展开后保留完整名称并换行。

计划任务编辑表单的标签、网格列、时间和日期时间输入增加宽度约束，保留原生时间输入及保存值。点击标签转入同一自定义下拉菜单，避免激活不可见的原生 select。

八插件下拉菜单取消内部搜索输入；长列表保留滚动和方向键、Home/End 操作，打开后聚焦已选项，不再因内置搜索输入主动唤起手机软键盘。没有修改官方影视搜索或页面上的内容搜索功能。

影视编辑原先缺少其他插件已有的触摸高亮重置，点击菜单时会先出现浏览器的矩形高亮。七个有菜单的插件统一禁用该原生点击高亮；鼠标/触摸焦点不显示额外边框，键盘的 `:focus-visible` 提示保留。

本地回归覆盖 320px、390px、横屏及桌面嵌入缩放的实际 Mihomo 与任务页面，检查长节点边界、不同计划类型切换、重复打开、标签激活和时间字段边界；另检查八插件共享下拉菜单和七插件导航、安装包与公共权限组件。测试请求使用本地模拟，不向 NAS 提交任务或更改策略。测试代码与图片保持本地，不进入安装包或 Git 索引。
