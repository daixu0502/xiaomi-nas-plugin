# 八插件业务文字字号统一

修正通用字号调整后仍被业务样式或代码文字规则覆盖的字段。电脑客户端的影片代码输入、系列只读值、SSH 公钥指纹与普通字段值统一为 16px/24px；独立说明段落与正文同级，不再因 `.note` 等类名缩小。字段原名、时间、徽标、次级状态等元信息保留 14px/21px，日志及配置编辑器保留等宽 14px/22px。标题与指标数字保留相应层级，图标字形保持原尺寸。

共享样式使用只作用于桌面插件内部、低选择器优先级的继承规则，消除不同业务容器中遗留的固定小字号；后续语义规则明确控制正文、字段值、元信息、表头、指标及日志。侧栏栏目标题同步到元信息字号。字体族和原生控件数据未变；没有新增脚本轮询、权限或字体下载。手机端保持既有基础文字规则。

本地验证直接检查八个插件原有页面和对话框文字，另使用真实影视编辑渲染函数生成代码输入及系列值，并填入 SSH 既有指纹控件。覆盖桌面 100%/80% 显示、实际字段与说明文字的计算样式及最小文字尺寸，同时回归手机基础指标、下拉菜单、任务编辑和影视操作。测试请求全部为本地模拟，未修改 NAS 媒体库、任务或代理策略。测试源、报告和截图不进入安装包或 Git 索引。
