# 小米 NAS 定时任务

## 功能说明

- 按计划启停或重启容器、从本地镜像创建容器、执行用户脚本、重启 NAS，以及清理指定范围内的旧文件。
- 支持每天、每周、工作日、周末、每月、指定日期、间隔、Cron、开机后和前置任务成功后触发。
- 提供任务模板、执行前检查、部分任务的失败重试、手动执行及清理预览。
- 查看调度状态、执行记录、失败原因及输出日志。

## 如何使用

### 安装与更新

使用完整源码或解压后的安装包，在本插件目录内执行。WSL / Linux 通过 root SSH 连接 NAS：

```bash
bash manage.sh install --ip 192.168.31.100 --users u123456789
```

在 NAS 本机以 root 运行时，省略 `--ip`：

```bash
bash manage.sh install --users u123456789
```

将示例 IP 和用户 ID 换成自己的值。直接运行 `bash manage.sh` 可进入交互菜单；安装和更新使用同一入口。安装后在小米客户端应用列表中打开本插件，必要时完全退出客户端再重进。

### 创建与执行任务

1. 打开“定时任务”，使用顶部“启动调度服务”或“停止调度服务”总开关。启动前会提示当前已启用任务数量，请先核对任务列表。
2. 从“模板”选择任务，或在“任务”中新建，填写操作对象、执行计划和超时时间。
3. 按需设置存储池、目录及 Docker 就绪检查；支持重试的任务可设置重试间隔和次数。
4. 保存后核对配置，再手动启用任务。新建任务和套用模板默认停用。
5. 可使用“立即执行”验证任务，在“记录”中查看结果及输出。清理任务先使用“预览清理”核对范围。

联动任务需选择同一用户的前置任务；只响应启用后的新执行结果，前置任务最终成功才触发。

### 卸载

```bash
bash manage.sh uninstall --ip 192.168.31.100 --users u123456789
```

NAS 本机省略 `--ip`，按提示确认。其他参数可用 `bash manage.sh install --help` 查看。

## 注意事项

- NAS 存储池需已挂载，目标用户需在小米客户端完成初始化；远程安装需能使用 root SSH 登录。
- 计划按 NAS 本机时区运行，每分钟检查一次；错过的普通计划不补跑，上次未结束则跳过。开机任务在启用后的下一次开机生效。
- 调度服务开关与单个任务开关独立；启动调度服务不会修改任务配置，已启用的任务将按各自计划执行。
- 调度心跳保存在可重建缓存中；没有任务或执行状态变化时，不因心跳重写持久任务文件。首页失败数仅统计近 24 小时，完整历史仍可查看。
- “立即执行”会跳过时间和前置任务限制，仍会检查配置的存储池、目录及 Docker 条件。
- 用户脚本以所属 NAS 用户执行。开启失败重试前，确认脚本可以安全重复运行，避免重复写入或删除。
- 重启 NAS 和 Docker 操作会影响其他用户；清理会永久删除届时符合条件的文件，预览不等于备份。
- 从本地镜像创建容器的任务不自动拉取镜像，也不配置端口映射、目录挂载或特权。复杂容器应先创建，再安排启停。
- 卸载会移除该用户的任务调度权限；已启动的容器和用户文件保留。
- 使用安装脚本卸载会取消本插件的自动恢复登记；仅在应用市场删除时，恢复服务可能将插件补回。
