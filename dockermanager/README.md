# 小米 NAS Docker 管理

## 功能说明

- 查看、创建、启动、停止和重启容器，查看容器日志、端口、挂载和详细配置。
- 拉取和删除镜像，管理存储卷，查看 Docker 网络。
- 更新容器镜像并按原配置重建，查看升级进度及结果。
- 查看 Docker 引擎状态和空间占用，启停引擎或批量操作容器。

## 如何使用

### 安装和更新

1. 在电脑的 **Ubuntu（WSL）终端**中，进入有 `manage.sh` 的插件文件夹，运行：

```bash
bash manage.sh
```

2. 输入 `1`，选择“安装 / 更新”，按提示输入 NAS 的 IP，再选择自己的账号。只有一个账号时会自动选择。
3. 等待提示安装成功，再到小米客户端的应用列表打开本插件。看不到时，退出客户端后重新打开。

更新也是这三步，已有配置会保留。需要先让电脑能用 root SSH 登录 NAS；还没开启时，见[SSH 开启步骤](../nas-root/README.md#开启-ssh)。

### 管理 Docker

1. 在应用列表打开“docker”，默认进入容器页；在“设置”页确认 Docker 引擎已运行，并查看系统信息和空间占用。
2. 在容器列表选择目标，查看详情、日志，或执行启停操作；创建容器时按需填写镜像、端口和挂载目录。
3. 需要更新容器时，使用镜像更新操作，核对重建信息后确认，并查看执行结果。
4. 在镜像、存储卷和网络页面查看相应资源；删除资源前核对其使用情况。

### 卸载

再次运行 `bash manage.sh`，输入 `2` 选择“卸载”，按提示选择账号并确认。

请用这个菜单卸载；只在小米客户端里删除，插件可能会自动恢复。手动指定账号等用法见[进阶说明](../docs/plugin-installation.md)。


### 工作台列表与资源统计

容器页按紧凑行展示名称、镜像和状态，常用启停和详情操作直接显示，日志、升级及删除等操作在“更多”中。容器 CPU 与内存合计使用 Docker 的实际采样，页面可见时每 10 秒更新；CPU 按 Docker 原始口径相加，多核负载可超过 100%。网络页显示子网，点击“查看详情”读取驱动、作用域和接入属性。统计失败时显示暂不可用，不影响容器管理。

## 注意事项

- NAS 存储池需已挂载，目标用户需在小米客户端完成初始化；远程安装需能使用 root SSH 登录。
- 容器创建、宿主机目录挂载和 Docker 管理具有较高权限，只给可信管理员使用。
- Docker 引擎和容器属于整台 NAS 的共享资源，停止、重启或批量操作会影响其他用户及服务。
- 更新容器会中断该容器服务，操作前备份重要数据；升级失败后的恢复结果以界面提示为准。
- 删除镜像或存储卷前确认不再需要；卸载插件会保留 Docker、容器、镜像、存储卷和用户文件。
- 使用安装脚本卸载会取消本插件的自动恢复登记；仅在应用市场删除时，恢复服务可能将插件补回。

页面右上角“外观主题”可选择跟随系统、浅色或深色，本地记忆选择；跟随系统时自动响应系统外观变化。

## 在线更新

电脑端点击左下角版本号，手机端点击底部版本号打开更新弹窗；发现新版本显示 `NEW`。打开插件时按缓存策略自动检查，也可手动点击“检查更新”。点击“立即更新”并确认后，后台自动下载、校验和安装，关闭页面仍会继续。完成后关闭插件窗口再打开。

“更新代理”支持 HTTP/HTTPS，例如 `http://127.0.0.1:7890`；按 NAS 账号在八个插件间共用，仅用于检查和下载安装包，不改变其他服务代理。认证用户名、密码分别填写，密码不会回传页面。修改后保存，启用代理时失败不会自动直连。

更新保留配置、任务、启用状态、已更新内核和 SSH 材料，验证失败自动回退。有下载、传输或关键任务时请稍后更新。首次使用需通过原安装器安装一次含在线更新组件的版本。签名发布与恢复细节见 [在线更新组件说明](installer/updater/README.md)。
## 稳定性与关闭页面后的行为

顶部运行／停止数量和容器列表使用同一次采样，手动刷新及窗口内自动刷新都会更新。存在健康检查的容器必须达到 healthy 才提交升级，等待预算为 60–600 秒；没有健康检查时会注明只验证持续运行。旧容器在验证前保留，事务在开机、后续变更或状态查询时恢复原网络与启停／暂停状态。容器回退不代表数据卷内容回退。
